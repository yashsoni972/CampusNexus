# CampusNexus — College ERP Platform

## How to Run the Project

### EASIEST WAY — Double click this file:
```
START_CAMPUSNEXUS.bat
```
It will automatically kill other Node processes and start both backend and frontend.

Then open your browser and go to:
```
http://localhost:3000
```

---

### Manual Way (VS Code):

**Terminal 1 — Backend:**
```
cd backend
npm run dev
```

**Terminal 2 — Frontend:**
```
cd frontend
npm start
```

Then open: **http://localhost:3000**

---

## Tech Stack
- Frontend: React.js + Tailwind CSS (Port 3000)
- Backend: Node.js + Express.js (Port 5000)
- Database: MongoDB Atlas (Cloud)
- Auth: JWT Tokens
